        VPN management is not available. It requires the wol-wifi service (set up with sudo ./deploy/hotspot-setup.sh).

        VPN notes

        The WOL-Server connects to an OpenVPN server as a client and is reachable over the VPN without port forwarding in the home network. Internet traffic does not go through the tunnel; magic packets always go to the Wi-Fi.

        Recommended: a separate client certificate for the Pi and a fixed address via client-config-dir on the server. For access from other VPN clients (e.g. a phone), the server needs client-to-client. The file must contain the certificates embedded (<ca>, <cert>, <key> …); scripts (up, script-security …) are not taken over for security reasons.

        SSH key for putting devices to sleep

        For the WOL-Server to put a device to sleep via SSH, this public key must be in ~/.ssh/authorized_keys of the chosen user on the target device.

        Setup on the target device

        Linux: add the key and allow the user to suspend without a password:

        echo '<key>' >> ~/.ssh/authorized_keys
echo "$USER ALL=(root) NOPASSWD: /usr/bin/systemctl suspend, /usr/bin/systemctl poweroff" \
  | sudo tee /etc/sudoers.d/wol-server

        Command on the device: sudo systemctl suspend

        Windows 10/11: install the OpenSSH Server under "Optional features" and add the key to C:\ProgramData\ssh\administrators_authorized_keys (admins) or %USERPROFILE%\.ssh\authorized_keys.

        Command: rundll32.exe powrprof.dll,SetSuspendState 0,1,0 (standby, with hibernation disabled) or shutdown /h (hibernate)
