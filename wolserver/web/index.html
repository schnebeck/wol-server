      Hinweise zum VPN

      Der WOL-Server verbindet sich als Client mit einem OpenVPN-Server und ist über das VPN erreichbar, ohne Portfreigabe im Heimnetz. Internetverkehr läuft nicht durch den Tunnel, Magic Packets gehen immer ins WLAN.

      Empfohlen: ein eigenes Client-Zertifikat für den Pi und eine feste Adresse per client-config-dir auf dem Server. Für den Zugriff anderer VPN-Clients (z. B. Handy) benötigt der Server client-to-client. Die Datei muss die Zertifikate eingebettet enthalten (<ca>, <cert>, <key> …); Skripte (up, script-security …) werden aus Sicherheitsgründen nicht übernommen.

      SSH-Schlüssel zum Schlafenlegen

      Damit der WOL-Server ein Gerät per SSH schlafen legen kann, muss dieser öffentliche Schlüssel auf dem Zielgerät in ~/.ssh/authorized_keys des gewählten Benutzers stehen.

      Einrichtung auf dem Zielgerät

      Linux: Schlüssel eintragen und dem Benutzer erlauben, ohne Passwort zu suspendieren:

      echo '<Schlüssel>' >> ~/.ssh/authorized_keys
echo "$USER ALL=(root) NOPASSWD: /usr/bin/systemctl suspend, /usr/bin/systemctl poweroff" \
  | sudo tee /etc/sudoers.d/wol-server

      Befehl im Gerät: sudo systemctl suspend

      Windows 10/11: Unter „Optionale Features“ den OpenSSH-Server installieren, Schlüssel in C:\ProgramData\ssh\administrators_authorized_keys (Admins) bzw. %USERPROFILE%\.ssh\authorized_keys eintragen.

      Befehl: rundll32.exe powrprof.dll,SetSuspendState 0,1,0 (Standby, bei deaktiviertem Ruhezustand) oder shutdown /h (Ruhezustand)
